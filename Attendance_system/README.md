# Attendance Management System

A desktop-based **Attendance Management System** developed using **Java Swing**, **JDBC**, and **MySQL**. This application allows users to manage student attendance records through a simple graphical user interface while storing data securely in a MySQL database.

---

## Features

* Add student details
* Calculate attendance percentage
* Store attendance records in a MySQL database
* Display attendance records in a table
* User-friendly Java Swing interface

---

## Technologies Used

* Java
* Java Swing
* JDBC
* MySQL

## Prerequisites

Before running the project, ensure you have:

* Java JDK 8 or later
* MySQL Server
* MySQL Connector/J (JDBC Driver)
* An IDE such as IntelliJ IDEA, Eclipse, or NetBeans

---

## How to Run

1. Create a MySQL database and the required `student` table.
2. Update the database credentials in `DBConnection.java`.
3. Add the MySQL Connector/J JAR file to your project.
4. Compile and run `Main.java`.
5. Use the GUI to add and manage student attendance records.
